# WebAdmin do Taxômetro (protótipo)

Protótipo de tela de gestão de tarifas. Não faz parte do app publicado: não há servidor, a resposta é simulada
(`infrastructure/AdminAdapter.js`) e nada é salvo. Fica fora de `src/` para não ir ao GitHub Pages nem ao service worker.

Para ver localmente, sirva a pasta do app (ex.: `npx serve .`) e abra `prototipos/admin/admin.html`; ele usa o CSS e o kit de `../../src/`.
